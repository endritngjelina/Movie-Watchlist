# Movie-Watchlist

Movie-Watchlist is a clean, professional movie watchlist application designed to help you manage, organize, and track the films you plan to watch. This repository offers several HTML implementations presenting different UI options for a personal movie watchlist app.

## Features

- Add, delete, and organize movies in your watchlist
- Multiple interface versions for different user experiences
- 100% HTML-based; no dependencies required
- Lightweight, fast, and simple for personal or demo use
